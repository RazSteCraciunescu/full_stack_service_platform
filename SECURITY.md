# Security policy

## Supported version

The latest version on the default branch receives fixes.

## Reporting a vulnerability

Do not publish credentials or a working exploit in a public issue. Use the repository owner's private contact method or GitHub's private vulnerability reporting feature when enabled.

Include:

- affected path or endpoint;
- reproduction steps;
- expected and observed behavior;
- impact assessment;
- suggested mitigation, when known.

## Demonstration boundaries

This repository contains local sample services and fictional data. It does not include authentication, production secrets or a deployed cloud environment. Before any real deployment, add authentication and authorization, restrictive CORS rules, rate limiting, managed secrets, production logging and dependency scanning appropriate to the environment.
