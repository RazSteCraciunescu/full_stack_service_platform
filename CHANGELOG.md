# Changelog

All notable changes to this repository are documented here.

## 1.0.0 - 2026-08-30

### Added

- Service-request dashboard, queue management, detail panel, comments, CSV export and demo reset.
- Dependency-free TypeScript/Node REST API with validation and deterministic fixture data.
- React, Vue, AngularJS and no-framework frontend implementations.
- Python/FastAPI reporting service, standalone PHP webhook and Laravel API example.
- MySQL schema, seed data, views, queries and optional repository adapter.
- OpenAPI contracts, Postman collection, Docker, Laragon and Azure deployment examples.
- Node, PHP, Python and Playwright test assets plus repository validation scripts.
