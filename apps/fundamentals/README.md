# Browser fundamentals client

A no-framework client built with semantic HTML, modular Sass and modern JavaScript. It demonstrates DOM events, Fetch API calls, filtering, responsive layout and a persisted theme preference without a build framework.

```bash
# Compile Sass after installing the root development dependencies
npx sass styles/main.scss dist/styles.css

# Or use the checked-in build served by the root application
npm start
# http://127.0.0.1:4174/fundamentals/
```
