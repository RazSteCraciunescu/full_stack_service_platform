REST API

Service Portal API guide

The runnable Node service uses JSON over HTTP. The complete OpenAPI 3.1 document is available at /api/openapi.json.

Endpoints

GET/api/health
GET/api/requests?q=&status=&priority=&category=
POST/api/requests
GET/api/requests/{id}
PATCH/api/requests/{id}
POST/api/requests/{id}/comments
GET/api/metrics
POST/api/demo/reset

Create example

curl -X POST http://127.0.0.1:4174/api/requests \
  -H "content-type: application/json" \
  -d '{
    "title": "Search results are not sorted",
    "description": "The newest requests appear below older items after changing a filter.",
    "category": "Usability",
    "priority": "Medium",
    "requester": {
      "name": "Demo User",
      "email": "demo.user@example.test"
    }
  }'
